# خشت · Khesht

قالب شروع برای اپ‌های وب فارسی که بدون اینترنت کار می‌کنند و روی گوشی نصب می‌شوند. دکمهٔ **Use this template** را بزن و یک اپ آماده تحویل بگیر: بدون اینترنت باز می‌شود، بین فارسی (راست‌به‌چپ) و انگلیسی (چپ‌به‌راست) جابه‌جا می‌شود، تاریخ شمسی یا میلادی نشان می‌دهد، داده‌ها را در IndexedDB نگه می‌دارد و از آن‌ها فایل پشتیبان می‌گیرد، بی‌آنکه چیزی از دست برود. تست، CI و انتشار روی GitHub Pages هم از قبل آماده است.

**دمو:** https://atefeh-sa93.github.io/khesht/

راهنمای کامل به انگلیسی: [README.md](README.md)

## چه چیزهایی دارد

- **کار کامل بدون اینترنت** و پیام «نسخه جدید آماده است» که فقط با تأیید کاربر صفحه را تازه می‌کند
- **نصب‌شدنی** با manifest فارسی و راست‌به‌چپ
- **فارسی و انگلیسی** با متن‌های تایپ‌دار، و جهت صفحه که پیش از اولین نمایش درست تنظیم می‌شود
- **تاریخ شمسی و میلادی**: ذخیره به‌صورت ISO میلادی، نمایش با تقویم کاربر
- **ارقام فارسی** در ورودی و خروجی
- **عددهای کنار هم در متن راست‌به‌چپ** با `<Nums>` که هر عدد را در `<bdi>` جدا می‌گذارد تا «۹/۱۲۰» برعکس دیده نشود
- **IndexedDB با migration نسخه‌دار** و تستی که یک migration واقعی را اجرا می‌کند
- **پشتیبان JSON که هیچ‌وقت چیزی پاک نمی‌کند**: کل فایل پیش از نوشتن بررسی می‌شود و فایل خراب چیزی را عوض نمی‌کند
- **یک قابلیت نمونه (یادداشت‌ها)** که در یک پوشه است و راحت پاک می‌شود
- **۱۳۹ تست واحد، ۳۵ تست E2E** روی build واقعی، ممیزی دسترس‌پذیری با axe در هر دو زبان، و CI و deploy خودکار

## استفاده از قالب

۱. **Use this template ← Create a new repository** را بزن.

۲. در ریپوی تازه: **Settings ← Pages ← Source: GitHub Actions**. بعد از هر push به `main` سایت روی `https://<you>.github.io/<repo-name>/` منتشر می‌شود.

۳. فایل **`app.config.ts`** را عوض کن: `APP_ID`، اسم‌ها، رنگ، `BASE_PATH` (برابر `/<repo-name>/`) و تقویم پیش‌فرض.

۴. **`public/icon.svg`** را با آیکون خودت عوض کن و `pnpm generate-icons` را اجرا کن.

۵. قابلیت خودت را بساز و نمونهٔ یادداشت‌ها را پاک کن. فهرست دقیق فایل‌ها در [README.md](README.md#removing-the-notes-example) آمده است.
